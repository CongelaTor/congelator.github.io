Politique de confidentialité

Dernière mise à jour : Juillet 2026

Présentation

Team CongelaTor développe plusieurs applications Android destinées au grand public.

Cette politique de confidentialité explique comment nos applications utilisent les données et quels services tiers peuvent être impliqués.

Données personnelles

Aucune de nos applications ne collecte directement d'informations personnelles permettant d'identifier un utilisateur.

Les données saisies dans les applications restent stockées localement sur l'appareil de l'utilisateur, sauf indication contraire dans les sections spécifiques ci-dessous.

Publicité

Certaines applications affichent des publicités fournies par Google AdMob.

Afin d'assurer le fonctionnement de ce service publicitaire, Google peut collecter certaines données techniques conformément à sa propre politique de confidentialité.

Pour plus d'informations : https://policies.google.com/privacy

Synchronisation et stockage Cloud

Alt'O Gaspi, Flowfy et Shop Store proposent une fonctionnalité facultative de synchronisation via Google Drive.

Lorsque cette fonctionnalité est activée, les données de l'application peuvent être sauvegardées sur le compte Google sélectionné par l'utilisateur.

Cette fonctionnalité est entièrement optionnelle.

Journaux d'erreurs

Certaines applications peuvent permettre l'envoi manuel d'informations de diagnostic afin d'aider à la résolution d'un problème.

Les informations transmises peuvent inclure :

  • le modèle de l'appareil ;
  • la version d'Android ;
  • la version de l'application ;
  • des informations techniques relatives à l'erreur rencontrée.

Aucune information n'est transmise automatiquement sans action de l'utilisateur.

Modifications

Cette politique peut être mise à jour à tout moment.

Toute modification sera publiée sur cette page.
